# Bonsai Night Watchman — CONTRACT

**Standing contract, authored for VULCAN.** The Bonsai Instant Citation launch site is the
front door for every pilot, district, and student who arrives from outreach. If it is down,
throwing errors, or serving a broken citation tool while I sleep, I want to know the moment
I wake — not from a support email three days later.

## Mandate

Every night at **03:00**, VULCAN's Night Watchman runs a set of **strictly read-only** checks
against the live site and, if anything is wrong, wakes me with **one** email. It never writes
to the site, never submits a form, never touches the Bonsai repositories. It watches; it does
not touch.

## What it checks (read-only)

- **HTTP 200** — every real, linked page answers 200: the homepage, the citation tool, guides,
  the extension page, privacy, schools, and terms.
- **Console-clean loads** — the homepage and the citation tool load in a headless browser with
  **zero** console errors, page errors, or failed script/style/document requests.
- **Internal link crawl** — every same-origin link reachable from the homepage returns 200
  (no dead internal links slipped into a deploy).
- **Engine smoke test** — the citation tool's engine actually mounts: its controls (style
  picker, type picker, fields, generate, output, workspace) render and the page loads clean.

## How it wakes me

- The **only** recipient is **vishnumovva@icloud.com**, fixed in code — the Watchman can wake
  exactly one person and no one else.
- **At most one email per 24 hours.** A failure storm is still one message.
- **Every attempt is logged** to `logs/night-watchman.log`, whether sent, suppressed, or
  refused.
- Until an app-specific password exists and I deliberately arm it, it runs **log-only**: it
  writes what it *would* send and sends nothing.

## Pre-flight decisions (recorded for review — 2026-08-05)

Both candidate hosts answered 200. I chose the canonical custom domain as `baseUrl`:

- `baseUrl` = **https://bonsaicitations.com** — the real production site (Vercel-served custom
  domain). `https://bonsaicitations.vercel.app` also serves the site and is kept as
  `fallbackUrl`, but the custom domain is what pilots visit, so it is what the Watchman guards.
- **Canonical page set** = the explicit `.html` pages linked from the homepage (all 200):
  `/`, `/tool.html`, `/guides.html`, `/it.html`, `/privacy.html`, `/schools.html`,
  `/terms.html`.
- **Dropped `/it`** (and the other extensionless clean-URLs) from the config. Although `/it`
  happens to return 200 via a Vercel clean-URL rewrite, its siblings are inconsistent —
  `/guides`, `/schools`, and `/privacy` all **404** — so the extensionless aliases are
  unreliable. The canonical linked page is `it.html`, which is what the config checks. This is
  exactly the "drop `/it` if dead" instruction, resolved by evidence: `/it` isn't dead, but it
  isn't canonical either, so the real page (`it.html`) is used instead.
- No `/about` page exists (404); it was never a linked path and is not in the config.
